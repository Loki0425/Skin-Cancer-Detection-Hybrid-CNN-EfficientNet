# Hybrid CNN + EfficientNet Skin Cancer Detection

## 📌 Project Description
This project is an AI-powered web application for early skin cancer detection using a Hybrid CNN and EfficientNet deep learning model.

## 🚀 Features
- Image Upload
- Skin Cancer Prediction
- Risk Level Classification
- Grad-CAM Heatmap Visualization
- AI-generated PDF Medical Report

## 🧠 Technologies Used
- Python
- TensorFlow / Keras
- EfficientNet
- Flask
- HTML / CSS / JavaScript

## 📂 Dataset
HAM10000 Skin Cancer Dataset

## ⚠️ Note
Due to GitHub file size limits, the trained model file is not uploaded. It can be shared on request.

## ▶️ Run Locally
pip install -r requirements.txt  
python app.py
